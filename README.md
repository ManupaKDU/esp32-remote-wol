# esp32-remote-wol
Remote Wake-on-LAN firmware for ESP32 boards using MQTT.

## Supported ESP32 boards

This firmware is **chip-family based**.  
Board vendor and layout do **not** matter.

Supported chip families:
- **ESP32**
- **ESP32-S2**
- **ESP32-S3**
- **ESP32-C3**

When building, select the matching PlatformIO environment.
